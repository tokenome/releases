# Contributing

Fixes to the README, the terms, the security policy, and the issue forms
are welcome as pull requests here.

Two directories are generated and overwritten by every release, so a
change to them would not survive: `plugins/` and `.claude-plugin/` (the
Claude Code plugin) and `deploy/` (the team server bundle). They come
from the main repository, which is private; describe the change in an
issue instead and we will carry it over.

Bugs and questions go through the issue forms. Security reports go
through the security policy, not a public issue.
